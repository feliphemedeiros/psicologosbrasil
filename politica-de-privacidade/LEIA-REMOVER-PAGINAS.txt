PÁGINAS REMOVIDAS (Serviços e Terapia para brasileiros nos EUA)

1) Suba os arquivos deste zip normalmente (substituindo os antigos).
   Atenção: o .htaccess é um arquivo "oculto"; ligue a opção de mostrar
   arquivos ocultos no Gerenciador de Arquivos da Hostinger para ver se subiu.

2) APAGUE no servidor (public_html):
   - a pasta  servicos/
   - a pasta  terapia-brasileiros-eua/
   - o arquivo css/eua.css
   - o arquivo css/servicos.css

3) Quem abrir os endereços antigos é levado automaticamente:
   /servicos/                  -> /psicologos/
   /terapia-brasileiros-eua/   -> página inicial
